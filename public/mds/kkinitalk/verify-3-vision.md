# Vision 일관성 측정 — 같은 사진 5회에 5가지 답

> 정답을 만들 수 없는 출력을, 정답 없이 검사하는 방법

## 왜 필요했나

- 식단 분석은 정답 세트를 만들기 어렵다 — "이 비빔밥이 몇 그램인가"는 **실제로 저울에 달아야** 한다
- 그래서 **정답 없이도 잴 수 있는 것** — 반복 일관성과 메타모픽 — 을 쟀다

| 재는 것 | 왜 |
|---|---|
| 같은 사진 N회 → 라벨 일치율(Jaccard) | 인식이 흔들리면 그 아래 숫자는 볼 의미가 없다 |
| 총 영양소 변동계수(CV) | **화면에 실제로 뜨는 숫자**의 흔들림 |
| 메타모픽 — 재인코딩·리사이즈·좌우반전·밝기 | 의미가 보존되는 변환에도 같은 음식인가 |

## 사진 두 장을 쓴 이유

| | |
|---|---|
| ![돌솥비빔밥](/assets/experiences/kkinitalk/bibimbap.jpg) | ![한정식 상차림](/assets/experiences/kkinitalk/hanjeongsik.jpg) |
| **돌솥비빔밥** — 단일 음식 | **한정식 상차림** — 반찬 다수 |

- 처음엔 비빔밥 한 장으로 쟀는데 **CV가 전부 0.0%** — 완벽해서가 아니라 **검사가 성립하지 않은 것**
- 면적을 합이 1이 되도록 정규화하므로 음식이 하나면 항상 1.000 — **흔들림은 "몇 개로 쪼갤 것인가"에서 나온다**

## 결과 — 같은 사진 5회

| | 돌솥비빔밥 (단일) | 한정식 (반찬 다수) |
|---|---|---|
| 서로 다른 결과 | 1종 | **5종 — 5회 모두 다름** |
| 라벨 Jaccard 평균 | 100% | **27.0%** |

| 항목 | 최소 | 최대 | CV |
|---|---|---|---|
| calories | 822.5 | 1042.0 | 10.6% |
| **sodiumMg** | **1452.5** | **2942.5** | **22.2%** |

- **나트륨이 2배 차이** — 고혈압 어르신에게 핵심 지표인데, 같은 사진을 두 번 찍으면 다른 판정이 나올 수 있다
- portion 판정도 실제로 뒤집혔다(large/regular) — 배율이 갈리면 그 음식의 영양소가 2배 차이
- 메타모픽 — **좌우 반전만 해도 Jaccard 15%**, JPEG 재인코딩에 칼로리 +54%

## 원인 — 라벨 공간이 자유롭다

```
rice / steamed_rice
soup / stew / stews / tofu_stew
vegetable_side_dish / seasoned_vegetables / stir-fried_vegetables / mixed_vegetables
```

- **인식이 틀린 게 아니라 이름과 입도(granularity)가 매번 다르다**
- 그 라벨이 곧 영양 테이블 조회 키 — 라벨이 흔들리면 총합이 흔들린다 → 라벨 안정화 작업으로 연결 (트러블슈팅 참고)
- 부수 발견 — 상차림은 느리다: 비빔밥 p50 2.1초 vs **상차림 p50 8.7초, 최악 12.7초**

## 남은 한계

- **일관성 ≠ 정확도** — 5번 다 똑같이 틀릴 수도 있다. 실제 그램 수·식약처 DB 대조는 여전히 없다
- 사진 2장 × 5회 — 통계적 신뢰구간을 말할 크기가 아니다

## 경험을 통해 배운 점

- **정답을 못 만들어도 검사할 수 있는 것이 있다**는 것 — 구조 불변식·일관성은 정답과 무관하게 잴 수 있다
- **측정이 다음 작업을 정해 준다**는 것 — 라벨 어휘 고정·다수결 검토·화면 불확실성 표시가 여기서 나왔다
- CV 22%짜리 값을 소수점까지 보여 주는 것은 **과신을 부른다**는 것
